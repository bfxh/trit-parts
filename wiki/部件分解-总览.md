# 部件分解 · 总览

目标：**一张 RGB 照片 → 带部件切分的 3D 网格**，全程不需要 GT 深度、GT 分割或相机位姿标定
（相机内参沿用数据集默认值）。

## 管线

```
RGB（一张）
 │
 ├─① 前景头（13 层三值全卷积）──────────► 前景掩码      IoU 0.969
 │
 ├─② 部件边界头（同一个网）──────────────► 边界图 → 分水岭 → 实例图
 │                                         部件 mIoU 0.496；pred/gt 0.81
 │
 └─③ 卷积深度头（3 层小网）──────────────► 相对 log 深度  8.11%（常数基线 9.01%）
        │
        ▼ 前景内反投影点云 → 体素 fill_solid → surface_nets → 闭合网格
        │
        ▼ 顶点投回源视角，取最近像素实例 id；面按三顶点多数票
        ▼
      part_001.ply … part_NNN.ply
```

## 读数汇总（留出 10 个未见场景）

| 指标 | 值 | 说明 |
|---|---|---|
| 前景 IoU | **0.969** | 前景头 vs GT seg（留出 80 帧均值） |
| 部件 mIoU | **0.496** | margin −1 / min-size 50 / merge-weak 0 |
| 部件数 pred/gt | **0.81（p90 1.18）** | 计数±1 36.2%；全对 7.5% |
| 深度相对误差 | **8.11%** | 形状对齐（常数基线 9.01%） |
| 单图网格 | 32k–43k 顶点 / 72k–100k 面 / 闭合 | 3 个留出场景 |
| 逐部件 PLY | 13 / 15 / 9 个 | GT ≈ 11 / 10 / 11 |

## 一句话

**每段都通，几何不够。** 8% 深度误差 ≈ 5 m 物体上 0.4 m 的误差，远大于 2 cm 体素，
所以网格"形状对、尺寸不可信"。适合做工具链验证与研究，不适合生产资产。
