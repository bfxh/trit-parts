# 部件分解 · 训练

## 1. 部件边界头

```bash
# 1) 标签
parts-inst prep --renders data/renders --scenes data/scenes --part-bnd

# 2) 训练（6000 步，384²，GPU）
parts-train --data <renders/scene0000,...> --seg-sub pbnd \
  --bnd-label 2 --bnd-weight 4 --steps 6000 --lr 1e-3 --res 384 \
  --state runs/pb/state.bin

# 3) 导出部署包
parts-cli export --state runs/pb/state.bin --out runs/pb/pb.tpm
```

### 为什么监督"边界"而不是"id"
直接让平面头回归"按左右排序的实例 id"学不会：它需要**全局比较**算子，纯卷积 + 逐像素 argmax
没有（2k 步塌成单 id）。边界是局部的、可学的；推理时再连通域/分水岭还原实例。

### 参数教训
- `--bnd-label 2`（边界 id）。填 1 = 把稀疏权重加到内部像素，mIoU 0.313 → **0.115**。
- `--bnd-weight` 8 会过预测（P 0.024），v6 上改 2–3；mat60 用 4。
- 检查点只有 `state.bin`；模型必须 `parts-cli export` 才是 `TPM1`。

## 2. 卷积深度头

```bash
parts-depth cnn-train --data <renders...> --holdout scene0050,...,scene0059 \
  --size 64 --epochs 60 --lr 0.01 --hidden 32 --dil 2 --stride 1 --full --f32 \
  --out runs/depth.dcn
```

配方要点（每一条都是修过的 bug）：
1. **逐图归一化**：`(ln d − med)/iqr` 裁 ±4（数据集级归一化会让 scale 塌到 0）。
2. **外置输出偏置 `out_b`**：Conv 的 bias 在 scale 乘法内，学 DC 时 scale 会被压到 0。
3. **scale 梯度按有效像素归一**：不归一化单步 ≈ 40，输出爆到 1e4。
4. **整图 64² 降采样**，不是中心裁剪。
5. `DCN3` 存 `dil`：否则推理按 RF 7 跑，和训练的 RF 13 不是一个函数。

### 多视角一致性（可选）
```bash
--mv-weight 1 --pair-gap 1 --mv-stride 2 --mv-tau 0.5
```
- 相邻视角（45°）把 A 的预测投到 B 当目标（stop-gradient）；
- **必须用软门** `1/(1+(d/τ)²)`：硬截断 `|d|>τ ⇒ 跳过` 在预测还差时会自锁（所有像素被判离群）；
- 几何自检 `--mv-check`：GT 互投 gap1 中位 0.3–0.6% 深度误差，gap4（180°）是遮挡。

## 3. 训练时间（本机）

| 任务 | 时间 |
|---|---|
| 部件头 6000 步（384²） | ~25–30 min |
| 深度头 60 epoch × 466 样本（64²，CPU，f32） | ~18 min |
| 同上，三值 | ~45 min |
| 深度头 + 多视角一致性 | ~35–47 min |

## 4. 扩数据要按比例加步数

6000 步在 400 帧（50 场景）上是 15 遍，在 2320 帧（290 场景）上只有 **2.6 遍**——
实测后者留出 mIoU 0.154、连训练场景也只有 0.222。**扩数据不配足步数只会掉点**（290 场景约需 35k 步）。

## 5. 别做的事（已实测）

- 加数据到 288 场景、同步数：**更差**（9.25% vs 8.30%）。
- 加大感受野（dil 4/6）：8.59/8.40%，无增益。
- 多尺度输入（RGB + 4×/8× 低通）：8.27/8.64%，无增益。
- 单帧/双场景能过拟合到 MSE 0.025–0.08 ⇒ 不是"学不动"，是**泛化不了**。
