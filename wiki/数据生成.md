# 数据生成与渲染参数

两个脚本：`scripts/s1_gen_scenes.py`（场景/清单）与 `scripts/blender_gt.py`（渲染 GT）。
**只造数据，不碰训练。**

## 1. 场景生成 `s1_gen_scenes.py`

```bash
python scripts/s1_gen_scenes.py --out data/scenes --scenes 240 --seed 23
```

| 参数 | 默认 | 含义 |
|---|---|---|
| `--out` | 必填 | 输出根目录（每场景一个 `sceneNNNN/` 或 `ptNNNN/`） |
| `--scenes` | 60 | 场景数 |
| `--seed` | 11 | 随机种子（确定性） |
| `--min-parts/--max-parts` | 24/80 | 每场景部件数区间 |
| `--objects-min/--objects-max` | — | 每场景物体数区间（装配体） |
| `--obj-sep` | 0.95 | 贴附布局时部件表面间距系数（<1 表示略微咬合） |
| `--obj-gap` | — | 物体之间的最小表面间距（米） |
| `--obj-min-parts/--obj-max-parts` | — | 每个物体的部件数区间 |

每场景输出：
- `parts.json`：`k` + 每个部件的三进制 digits（id → k 位）；
- `objects.json`：部件中心 / 种类（cube/cylinder/sphere/torus）/ 缩放 / 旋转 / 材质标签
  （wood/metal/stone/fabric，与形状解耦）。
- `scenes.json`：整批的汇总。

**布局**：平板 / 塔 / 环 / 团簇 / 链（团簇是「新部件贴在随机已有部件外侧」）。

## 2. 渲染 `blender_gt.py`（Blender 4.2，headless）

```bash
blender -b --factory-startup -P scripts/blender_gt.py -- \
  --out data/renders/scene0000 \
  --objects-json data/scenes/scene0000/objects.json \
  --frames 8 --res 384 --samples 16 --device GPU
```

| 参数 | 默认 | 含义 |
|---|---|---|
| `--out` | 必填 | 渲染输出目录 |
| `--objects-json` | 无 | 外部部件清单（给了就忽略内置布局） |
| `--frames` | 16 | 帧数（绕物体一圈） |
| `--res` | 512 | 分辨率（方图） |
| `--samples` | 16 | Cycles 采样数 |
| `--device` | GPU | CPU / GPU |
| `--layout` | A | 内置布局（A/B/C…） |
| `--radius` | None | 相机半径；None 用布局默认 |
| `--elev-deg` | None | 仰角；None 用布局默认 |
| `--elev-sweep` | 0 | 逐帧仰角正弦扫描幅度（度） |
| `--light-az/--light-el/--light-energy` | None | 主光方位/仰角/能量 |
| `--world-strength` | None | 环境光强度（默认 0.35） |
| `--hue/--value` | None | 材质色相旋转 / 明度乘子 |
| `--color-random/--color-seed` | 关/1 | 逐部件随机色（防颜色捷径） |

每帧输出：
`rgb/`（sRGB）、`depth/`（**相机空间 Z**，米）、`normal/`（**世界系**）、`seg/`（object index）、
`meta/`（K / T_wc / T_cw / 相机参数），以及 `manifest.json`（配置 + 每帧 meta + 物体表）。

**实测成本**：8 帧 384² GPU 约 **3.3–5.0 s / 场景**（渲染 0.3 s/帧，其余是 Blender 启动）。

## 3. 相机必须对齐（血的教训）

不同批次的相机参数如果不同，就是**两个域**：
mat60 逐场景 radius 3.9–8.08 / elev 10–47°（前景占比 0.112），
而默认参数渲出来 radius 3.4 / elev 12°（前景 0.349）——留出 mIoU 直接掉 0.05。
用 `scripts/rerender_matched.py` 从参考集 manifest 自举相机并保证 `radius ≥ 1.35×簇半径`。
