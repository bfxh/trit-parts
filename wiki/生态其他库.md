# 生态其他库

本页汇总 trit 生态里其他的三进制库（本库只依赖其中的 `trit-look`，其余为同源技术栈）。

## trit-immune · 安全裁决

三值裁决域：**allow / deny / unknown**。核心取向是 **fail-open 必须被显式发现**——
"没证据"不能悄悄折成"放行"。工程上：
- 双轨编码 + 一致性检查（冲突的 rail 直接判红）；
- 裁决规则做单点变异，测试必须抓住（否则等于没有规则）；
- 与 `trit-policy`/`trit-belnap` 共用四值/三值语义。

## trit-re · 逆向工程辅助

ELF/PE 的静态与动态证据提取。已落的一块：**GOT 基址按寄存器跟踪**
（`get_pc_thunk.ax/.dx` 等漏检问题），把 `mov 0x10(%eax),%ecx` 这类访问还原。
定位是"证据提取器"，不是反编译器。

## trit-chem · 化学热力学

用三值/符号方法做热力学计算（NaCl、Fe 的沸腾/升华）。已知读数：NaCl 沸点 1788 K（+2.9%）、
Fe 3003 K（−4.2%）；解析熵积分把 Clapeyron 斜率误差从 8.3% 压到 0.002%。

## trit-codec · 三值编码

三元数据 ↔ 二进制的位打包。约束：二进制/三值边界接近零开销；
非法 rail 必须规范化；`from_binary` 多余字要截断。等价编码是"多种位模式表示同一三值串"，
所以编码器有规范形与距离判据。

## trit-sat / trit-circuit / trit-bdd / trit-eval

- `trit-sat`：三值可满足性（DPLL 风格），带资源上限与预算门。
- `trit-circuit`：三值门电路、AIG 导入导出。
- `trit-bdd`：三值决策图。
- `trit-eval`：表达式求值与化简（吸收律、幂等律要按代数区分）。

## trit-learn / trit-train

量化与训练层。本库已把 `Ste` 内联（`src/ste.rs`），不再依赖它们；
`trit-train` 提供可发布的线性层与训练循环。

## trit-wasm / sansheng

- `trit-wasm`：wasm32 构建，浏览器/Node 里跑三值算子。
- `sansheng`：伞包，只做 `pub use` 转发。

## 怎么核对

每个库的 README/文档是权威；本页只做导航与关键取向说明，具体 API 以源码为准。
