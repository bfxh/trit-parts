# 训练与量化（trit-learn）

三值权重的训练问题是：`round()` 的导数处处为 0。解决办法是 **STE（直通估计）**——
前向量化，反向往回传时用一个"门函数"把梯度近似地送回去。

## 1. 三种 STE 门

有效权重 `E = q · scale`，`q = round(w/scale).clamp(-1,1)`，`w` 是 f32 latent。

| 门 | 反向系数 |
|---|---|
| `Identity` | 1（经典 STE） |
| `Clipped { ratio }` | `|w/scale| ≤ ratio ? 1 : 0`（已饱和的权重不再动） |
| `Soft` | `max(0, 1 − (w/scale)²)`（边界连续） |

实现在 `src/ste.rs`（本仓自带，四行公式 + 单测）。

## 2. 量化口径

- **逐输出通道**一个 `scale`（不是逐权重、也不是全局）。缺它三值只有 ±1，函数斜率调不了。
- bias 与**输出层**保持 f32。输出层三值化会让回归目标不可达。
- 初始化要越过三值死区：`|w| < 0.5` 会被量化成 0，所以初值乘 3。

## 3. 训练循环的坑（都踩过）

1. **逐像素/逐 batch 的梯度要不要除以 n**：权重走 Adam 时无所谓（自适应），但**scale 走 SGD 时
   必须按像素数归一**。不归一化时单步 ≈ `lr·Σ像素 ≈ 40`，scale 在 ±10 与 1e-3 之间振荡，
   输出直接爆到 1e4。
2. **bias 在 scale 乘法之内**（`out = scale·(b + Σq·x)`）：学全局 DC 时优化器会把 scale 推向 0，
   网络"自杀"。回归头需要**外置**输出偏置（见 [部件分解 · 训练](部件分解-训练)）。
3. **剪裁目标与 sign 损失**：sign-L1 在裁到 ±4 的归一化目标上方向恒定，会把 ReLU 推死；
   改 log 深度 + L2 后正常。
4. **夹具让防御码空转**：断言"某值保持 0"前，先问有没有输入能把它弄脏。

## 4. 训练配方（部件头）

```bash
parts-train --data <renders...> --seg-sub pbnd --bnd-label 2 --bnd-weight 4 \
  --steps 6000 --lr 1e-3 --res 384 --state runs/pb/state.bin
```

- `--bnd-label 2` 是**边界 id**（0 背景 / 1 内部 / 2 边界）。填 1 等于把权重加到内部像素上，
  留出 mIoU 从 0.313 掉到 0.115——这是本库最贵的一个参数错误。
- `--bnd-weight` 是稀疏类加权：边界只占前景 4–16%，普通 CE 一个点都不预测。
- 检查点只有 `state.bin`（可续训）；部署包要用 `parts-cli export` 转 `TPM1`。
