# 术语表

## 三值

| 术语 | 含义 |
|---|---|
| **tri / trit** | 三值位：{-1, 0, +1}。Unknown 与 0 语义不同 |
| **STE** | 直通估计：前向量化、反向往回传近似梯度 |
| **latent w / q / scale** | 训练保留的 f32 权重 / 量化后的 {-1,0,+1} / 每通道缩放；`E = q·scale` |
| **rail** | 双轨位编码里的非法位型（B3 的 `11`） |
| **Kleene / Łukasiewicz / Bochvar** | 三种三值强代数；混用会静默错 |
| **FiLM** | 按类别对隐层做逐通道缩放/平移 |
| **BN（折叠）** | 推理时把 BatchNorm 折进卷积权重 |

## 分割

| 术语 | 含义 |
|---|---|
| **部件 id / digits** | 清单里每个部件一个 id，用 k 位三进制编码 |
| **约束 argmax** | 只在清单允许的 id 上取最大，结构上不可能输出清单外 id |
| **pbnd** | 部件边界标签：0 背景 / 1 内部 / **2 边界** |
| **分水岭 `split_by_boundary`** | 前景减边界后，把边界像素多源 BFS 归最近块 |
| **`merge_weak τ`** | 相邻两块的共享边界平均 logit 间隔 < τ 就合并（并查集） |
| **pred/gt** | 预测实例数 / GT 部件数；p90 看最坏帧 |
| **mIoU** | 每个 GT 部件的最佳 IoU 均值；多余预测不扣分 |

## 几何与 3D

| 术语 | 含义 |
|---|---|
| **surface nets** | 体素等值面提取，输出四边形/三角形网格 |
| **fill_solid** | 单视图下把壳体填实（回填不可见体积） |
| **边界边** | 只被一个三角形共用的边；0 = 闭合 |
| **LSCM** | 最小二乘保角映射（UV 展开） |
| **chart** | 按法线相似度聚类出的可展开面片 |
| **UV 密度 spread** | p95/p05，衡量展开拉伸 |
| **体素 IoU** | 点云/网格体素化后的交并比 |

## 训练与评测

| 术语 | 含义 |
|---|---|
| **形状对齐误差** | 用该图 GT 的中位/IQR 反归一后再算相对误差（只量形状） |
| **固定尺度误差** | 用训练集平均统计反归一（可部署口径） |
| **多视角一致性** | 相邻视角预测互投的几何约束（stop-gradient + 鲁棒门） |
| **`--mv-check`** | 用 GT 深度互投验证相机缩放/投影是否正确 |
| **工作点** | margin / min-size / merge-weak 的组合；在训练场景上选 |

## 格式

| 头 | 用途 |
|---|---|
| `TPM1` | 部署包（q/scale/γ/β/bias） |
| `TPC7` | 训练网（含 BN/FiLM/heads/dilation） |
| `TPNT3` | 训练存档 state.bin |
| `DCN3` | 深度头（med/iqr/ternary/out_b/dil） |
