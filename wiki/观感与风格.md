# 观感与风格（trit-look）

独立仓：<https://github.com/bfxh/trit-look>。本库通过 `trit_parts::look` 转发使用（pin rev 保证可复现）。

## 1. 为什么单独做一个库

"看起来像不像"必须能**测量**，否则每次调参都在凭感觉。`trit-look` 把观感拆成可算的代理量：

| 指标 | 含义 |
|---|---|
| `stroke` | 笔画/结构尺度（能分辨的最小纹理周期） |
| `coherence` | 结构张量的相干度（0 各向同性，1 强方向） |
| `contrast` | 对比度 |
| `hf1/hf2/hf4` | 多尺度高通能量（细节量） |
| `boundary_ratio` | 边界能量占比 |
| `levels` | 有效灰阶数（量化程度） |
| `warmth` / `sat` / `hue_entropy` | 色温/饱和/色相熵 |

这些量在本库里有直接用途：
- quilt 合成后检查 `stroke`/`coherence` 是否被抹平（实测实拍扫描件对比度 −78% 就是这样发现的）；
- 风格预设的单调性验收；
- 材质分风格（wood=cel / metal=epic）的产物级定位（差异像素占比对得上三角形占比）。

## 2. 风格预设

三个预设 × 单一强度 `t`（S6.7 止损后的形态——多因子强耦合，调不动）：

| 预设 | 特征 |
|---|---|
| `cel` | 色阶量化 + 描边，卡通感 |
| `oil` | 柔化 + 色阶 + 局部对比，油画感 |
| `epic` | 高对比 + 冷调 + 强结构 |

`Style` 的显式旋钮：`contrast / levels / warmth / sat / stroke`。后处理顺序：色阶最后，
`stroke` 用分数半径（整数步会跳变）。

## 3. 本库内的使用

```bash
# 给贴图套风格
parts-3d tex-stylize --tex in.ppm --preset oil --strength 0.8 --out out.ppm
# 按材质给不同风格（需要清单）
parts-3d mesh-tex ... --style-by-material "wood=cel:1,metal=epic:0.5"
```

## 4. 已否证

- **风格因子强耦合**：五个旋钮互相抵消，同时调不出目标观感 ⇒ 改预设 + 单强度。
- **stroke 量具封顶 32 px**：更粗的纹理测不出来，指标饱和。
- 扩散生成方向的六旋钮（分辨率/步数/方向损失/STM/相干损失/膨胀）全部无效 ⇒ 纹理改走非参数 quilt。
