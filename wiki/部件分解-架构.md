# 部件分解 · 架构

## 1. 模块地图

| 模块 | 文件 | 职责 |
|---|---|---|
| `ste` | `src/ste.rs` | 三种 STE 门（本仓自带） |
| `tconv` | `src/tconv/{conv,bn,net,io,diffusion}.rs` | CPU 三值卷积栈、BN、FiLM、保存/加载 |
| `net` | `src/net/{layer,model}.rs` | 全卷积网（13 层）+ GPU 前反向 |
| `backward` | `src/backward.rs` | E→latent 的 STE 应用、affine 反向 |
| `gpu` / `gpu_bwd` / `backend_wgpu` | | wgpu 算子和反向 |
| `parts` | `src/parts.rs` | 清单解析、k 位三进制 id 编解码、约束 argmax、评估 |
| `inst` | `src/inst.rs` | 边界图、连通域、分水岭 `split_by_boundary*`、`merge_weak` |
| `mesh` | `src/mesh/{build,morph,io}.rs` | 体素、surface nets、填实、清理、PLY |
| `atlas` / `uv` | | 法线聚类分 chart、LSCM、货架打包、烘焙、UV 统计 |
| `tex` | `src/tex/{quilt,style,tiles}.rs` | quilt 合成、风格预设、程序化材质 |
| `depth` / `depthnet` | | 线性深度头 / 卷积深度头（多尺度、多视角一致性） |
| `look` | `pub use trit_look` | 观感度量（外部独立仓） |
| `light` | `src/light.rs` | 朗伯光照求解、重打光 |
| `splat` / `fuse` / `geo` | | 高斯/点云、多视图融合、相机几何 |
| `matnet` / `ridge` / `ood` | | 材质分类、岭回归、域外闸门 |

## 2. 权重格式（全文本，逐位可复现）

| 头 | 用途 | 内容 |
|---|---|---|
| `TPM1` | 部署包 | 只含 q/scale/γ/β/bias（推理用） |
| `TPC7` | 训练网 | 层维度 + w/b/scale + BN + FiLM + heads + dilation |
| `TPNT3` | 训练存档 | state.bin（可续训，含优化器状态） |
| `DCN3` | 深度头 | med/iqr/ternary/out_b/**dil** + 三层卷积 |

> `DCN3` 里的 `dil` 是血的教训：不存膨胀率，推理会按 dil=1 加载，跑的不是训练时那个函数。

## 3. GPU / CPU 分工

- **GPU（wgpu）**：卷积前向/反向、BN、优化器更新；推理二进制 `parts-* --features gpu`。
- **CPU**：STE 的 E→latent 映射、量化、几何（体素/网格/UV）、分水岭与并块、评测指标。
- 单测不依赖 GPU（`cargo test` 无 feature 也能跑 133 条中绝大部分）。

## 4. 命令一览

| 命令 | 作用 |
|---|---|
| `parts-3d infer / infer-ids / eval` | 部件 id 推理与 3D 评测 |
| `parts-3d mesh / fuse / splat / occ / align / obs-split` | 重建与融合 |
| `parts-3d mesh-tex / tex / tex-quilt / tex-stylize / tex-gen` | 纹理、风格、图集 |
| `parts-3d light-* / material-* / look / style` | 光照、材质、观感 |
| `parts-train` | 部件头训练（--seg-sub pbnd / --bnd-label 2） |
| `parts-cli export` | state.bin → TPM1 |
| `parts-inst prep / eval` | pbnd/prep、实例评测（含 `--merge-weak`） |
| `parts-depth train / eval / cnn-train / depth-iou / mesh-single` | 深度与单图网格 |
| `parts-guard` / `parts-ood` | 训练看门狗 / 域外闸门 |
