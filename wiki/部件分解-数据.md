# 部件分解 · 数据

## 1. 生成：程序化部件簇

`scripts/s1_gen_scenes.py` 只造数据，不碰训练：

```bash
python scripts/s1_gen_scenes.py --out data/scenes --scenes 240 --seed 23
```

每场景：
- 部件 24–80 个（cube / cylinder / sphere / torus），逐部件随机缩放/旋转；
- 布局 5 种（平板/塔/环/团簇/链）；
- 输出 `objects.json`（渲染器输入）与 `parts.json`（id → k 位三进制 digits 清单）；
- 带**材质标签**（wood/metal/stone/fabric），与形状解耦。

实测生成 ~0.1 s/场景。

## 2. 渲染：Blender headless

`scripts/blender_gt.py`（Blender 4.2，自带 numpy）：

```bash
blender -b --factory-startup -P scripts/blender_gt.py -- \
  --out data/renders/scene0000 \
  --objects-json data/scenes/scene0000/objects.json \
  --frames 8 --res 384 --samples 16 --device GPU
```

每帧输出：`rgb/`（sRGB 8bit）、`depth/`（相机空间 Z，米）、`normal/`（**世界系**）、
`seg/`（pass_index）、`meta/`（K、T_wc、T_cw、相机参数）。

**实测 3.3–5.0 s/场景**（8 帧 384²，GPU；其中渲染 0.3 s/帧，其余是 Blender 启动）。
240 场景约 15 分钟。

## 3. 标签口径

| 目录 | 值 | 用途 |
|---|---|---|
| `seg/` | 0 背景，≥1 部件 id | 部件级评测的 GT |
| `pbnd/`（`parts-inst prep --part-bnd`） | 0 背景 / 1 内部 / 2 **边界** | 边界头训练 |
| `inst/`、`bnd/`（`prep`） | 实例序 | 实例级评测 |

**关键**：`pbnd` 的**边界是 id 2**。训练时 `--bnd-label 2`；填 1 等于给内部像素加权，
mIoU 从 0.313 掉到 0.115。

## 4. 场景规模与遮蔽

- 前景只占全图 ~15%，所以**整图降采样**（384→64）而不是中心裁剪；后者丢掉全局布局。
- 场景中位深度 4.5–6.7 m，簇内 log 深度 IQR ~0.18（形状信号不大）；
  跨场景相机距离 std 0.275 ⇒ 单图推不出绝对尺度。
- 密集簇（可见 6–26 部件）是评测里过分割的来源。

## 5. 数据规模实测

| 数据集 | 场景 | 用途 |
|---|---|---|
| `mat60` | 60（8 帧） | 部件头/深度头的主训练与留出 |
| `mat240` | 240（8 帧） | 深度扩容否证（同步数反而更差） |
| `v6` | 100（8 帧，2 物体） | 早期实例分割（mIoU 0.7965） |
| `occl8b` | 8 | 互穿/遮挡对照 |
