# 部件分解 · 评测

## 1. 指标定义

| 指标 | 定义 |
|---|---|
| **部件 mIoU** | 每个 GT 部件的最佳 IoU 的**均值**（未匹配按 0）。多余预测**不扣分** → 必须配合 pred/gt 一起看 |
| **pred/gt** | 平均预测实例数 / 平均 GT 部件数；p90 表示最坏 10% 帧 |
| **计数±1 / 全对** | 预测数与 GT 相差 ≤1 / 完全相等的帧占比 |
| **前景 IoU** | 前景头 vs GT seg |
| **边界 P/R/F1** | 边界像素（容差 2 px）与 GT 边界比 |
| **深度相对误差** | 形状对齐：用该图 GT 中位/IQR 反归一后的 `|exp(Δln d) − 1|` 均值 |
| **δ<1.25** | `max(p/g, g/p) < 1.25` 的像素占比 |

## 2. 默认工作点（= 推荐）

```
--bnd-margin -1 --min-size 50 --merge-weak 0
```

| 工作点 | mIoU | pred/gt（p90） | 计数±1 | 全对 | 边界 F1 |
|---|---|---|---|---|---|
| **默认（−1 / 50 / 0）** | **0.458** | **0.94（1.50）** | 27.5% | **10.0%** | 0.376 |
| −1 / 50 / 不并 | 0.487 | 1.15（1.82） | 27.5% | 3.8% | 0.376 |
| −2 / 50 / 不并 | 0.559 | 2.05 | 6.2% | 1.2% | 0.283 |
| 0 / 50 / 不并 | 0.313 | 0.53 | 10.0% | 0.0% | 0.413 |

选点方法：**在工作点训练集上选**（−1 训练 0.554，−2 训练 0.596），留出只报数。

## 3. 负结果（同口径实测）

| 手段 | 结果 |
|---|---|
| 固定 `--min-size` 200 / 500 / 1000 | mIoU 0.462 / 0.368 / 0.274；200 已**欠**分割 |
| `--merge-ratio 0.3`（中位面积） | mIoU 0.461、pred/gt 0.90 |
| `--merge-max 0.05`（最大块） | mIoU 0.462、pred/gt 0.70 |
| `--merge-weak 0.5 / 1.0` | mIoU 0.361 / 0.302 |

结论：**面积法并块是错工具**（会并真部件）；只有**边界强度**并块（`merge_weak`）是有效方向。
