# 工程门禁与复现

## 1. 本库的门

| 门 | 判据 |
|---|---|
| `cargo fmt --check` | 格式 |
| `cargo clippy --all-targets -- -D warnings` | 零警告（含测试目标） |
| `cargo test --features gpu` | **133 条**全绿 |
| `cargo doc -D warnings` | 文档链接无断链 |
| `module_budget.py`（上游仓） | 单文件 ≤800 行，基线为空 |

## 2. 变异门（在上游仓）

`scripts/mutation_check.py` 对关键规则做**单点文本变异**，对应单测必须变红：

| 变异 | 抓住它的测试 |
|---|---|
| 深度头丢掉外置 `out_b` | `forward_includes_external_bias` |
| scale 梯度不按像素归一 | `learns_constant_offset` |
| 多视角一致性去掉鲁棒权重 | `mv_gate_skips_outliers` |
| 弱边界并块失效 | `merge_weak_folds_low_margin_pairs` |
| （历史）STE/量化类 3 条 | 见上游仓登记表 |

**空集判红**：包的登记表是 0 条时门直接判红——"没登记"不能当"通过"。

## 3. 复现一条读数的最小集

```bash
cargo test --release --features gpu            # 133 条
parts-inst eval --model pb.tpm --renders R --scenes S --gt part --boundary --k 5 --res 384
# 期望：mIoU 0.496、pred/gt 0.81（p90 1.18）、前景 IoU 0.969
```

## 4. 训练可复现

- 权重全文本；随机性只来自 seed（`splitmix64`）。
- 检查点 `state.bin` 带步数与 RNG 状态，可续训。
- 导出 `TPM1` 后推理逐位一致（`parts-parity` 二进制做整网对拍）。

## 5. 交接与台账（上游仓）

多智能体协作时：开工先读 `_handoff/LEDGER.md`，收工写自己的条目并跑
`check_handoff_sync.py`（必须 RC=0）。条目编号可能被并发会话占用——取空闲号，别拿 max+1。

## 6. 常见假红

| 症状 | 原因 |
|---|---|
| 本地绿、CI 红 | CI 的 clippy 版本更新（如 `manual_is_multiple_of`）；跑 `--all-targets` |
| 文档门红 | 注释里的 `[0,1]` 被当 intra-doc link——包成代码 |
| 训练读数漂 | 用了旧二进制（先比 exe 与源码 mtime） |
| 变异门红 | 换了包但登记表没更新（空集判红） |
