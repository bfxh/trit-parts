# 局限与已否证的方向

## 硬限制

1. **单目深度 8.11%**，离可用的 ≤2–3% 差一个量级；网格几何不可信。
2. **密集簇仍过分割**：最坏帧 24 个部件 vs GT 10。边界头精确率 0.26。
3. **合成域**：只对程序化生成的部件簇有效；真实照片属域外（有 OOD/取景闸门，但没有拒识能力时不可靠）。
4. **相机内参**：用数据集默认 35 mm/36 mm；真实照片未标定。
5. **可见性**：单视图只看到正面，背面由 `fill_solid` 臆测；切分对背面是投影外推。

## 已否证（别重复踩）

| 方向 | 证据 |
|---|---|
| 纹理扩散（六旋钮） | 分辨率/采样步数/方向损失/STM/相干损失/膨胀 全部无效（§6.4x） |
| 单图梯度估光照方位 | 四个已知方位全估成 356.8° |
| 深度：加数据 | 288 场景同步数 9.25% vs 49 场景 8.30% |
| 深度：感受野 | dil 4/6 = 8.59/8.40% |
| 深度：多尺度输入 | 6/9 通道 = 8.27/8.64% |
| 深度：量化精度 | 三值 ≈ f32 |
| 深度：多视角一致性 | 8.11%（唯一有正号，但幅度不够） |
| 过分割：固定 min-size | 200 即欠分割 |
| 过分割：按面积并块 | 并掉真部件 |
| 平面头直出实例 id | 2k 步塌成单 id（mIoU 0.346） |
